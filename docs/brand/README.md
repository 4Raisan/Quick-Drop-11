# Quick Drop 11 brand assets

The mark combines a drop with a lightning bolt: temporary sharing with a quick transfer. Blue and violet match the app's interface.

| Asset | Use |
| --- | --- |
| `icon.svg` | Square app icon; transparent outside the rounded tile |
| `wordmark.svg` | Horizontal logo on a light or neutral background |
| `banner.svg` | Dark README or repository banner |
| `../../public/favicon.svg` | App favicon; same artwork as the icon |

These are editable SVG originals, not bitmap exports. Keep the mark's proportions and leave clear space around it. Architecture diagrams are static SVG images in docs/diagrams, embedded in the README and architecture guide without interactive controls.
